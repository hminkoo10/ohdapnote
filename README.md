# 오답노트 (OhdapNote)

문제집과 답지(PDF 또는 사진)를 올리면 **문제 번호를 자동으로 찾아 표로 만들어 주고**,
틀린 문제만 골라 **문제 / 답지(해설) / 문제+답지** PDF로 내보내는 윈도우용 수학 오답노트 프로그램입니다.

- 같은 번호가 여러 번 나오는 책(단원마다 1번부터 다시 시작)도 **쪽 번호와 함께** 표에 표시합니다.
- 문제마다 짝이 되는 해설을 답지에서 자동으로 찾아 줍니다.
- 디지털 PDF는 글자 위치로, 스캔본·사진은 OCR(문자 인식)로 번호를 찾습니다. 인터넷 없이 동작합니다.
- 선택 기능: 무료 **Gemini API**(Google AI Studio) 키를 넣으면 자동 인식이 애매한 쪽을 AI로 다시 인식합니다.
- 설치형 프로그램이며 **새 버전이 나오면 자동으로 업데이트**됩니다.

## 설치

1. [Releases](https://github.com/hminkoo10/ohdapnote/releases) 에서 `OhdapNote-Setup-x.y.z.exe` 를 내려받아 실행합니다.
2. 코드 서명 인증서가 없어서 처음 실행할 때 “Windows의 PC 보호” 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
3. 설치가 끝나면 바탕화면/시작 메뉴의 **오답노트**를 실행합니다.

업데이트는 프로그램이 켜질 때(그리고 4시간마다) 자동으로 확인해서 내려받고, 다 받으면 화면 오른쪽 위에
**“재시작하여 설치”** 버튼이 나타납니다. 그냥 두면 프로그램을 끌 때 설치됩니다. (설정 → 업데이트 확인으로 직접 확인도 가능)

## 사용법

1. **새 오답노트 만들기** → 이름 입력 (예: `쎈 수학Ⅰ`)
2. **문제집**과 **답지** 칸에 파일을 끌어다 놓거나 클릭해서 고릅니다.
   - PDF 1개, 또는 사진(JPG·PNG) 여러 장(파일 이름 순서대로 쪽이 됩니다).
   - PDF 여러 개를 고르면 이름 순서대로 이어 붙입니다.
3. 필요하면 옵션을 정하고 **분석 시작**
   - **분석 쪽**: 예) `5-180`, `3-10, 15`. 답지는 앞쪽 *빠른 정답* 표를 빼 주면 짝 맞추기가 더 정확합니다.
   - **번호 모양**: 보통 `자동`. 잘 안 잡히면 `1. 2. 3.` / `0001` 등으로 직접 지정하세요.
   - **다음 단/쪽으로 이어짐**: 해설이 다음 단·다음 쪽으로 넘어가는 경우(답지는 기본으로 켜짐).
   - **PDF 1쪽 = 책 ○쪽**: 표에 책에 인쇄된 쪽 번호로 보이게 맞춥니다(쪽번호가 글자로 있으면 자동으로 맞춰짐).
4. **문항 선택** 탭: 쪽마다 번호 버튼이 나옵니다. 틀린 번호를 누르세요.
   - 번호에 마우스를 올리면 오른쪽에 문제와 해설이 미리 보입니다.
   - 쪽 번호 버튼을 누르면 그 쪽 문항을 한꺼번에 선택/해제합니다.
   - **빠른 선택** 칸: `12쪽: 3, 5, 7-9` 처럼 쪽과 번호로, 또는 `15, 22` 처럼 번호만(같은 번호가 여러 쪽에 있으면 모두) 입력.
   - 주황 점이 있는 번호는 답지에서 짝을 못 찾은 것입니다. 미리보기의 목록에서 직접 고를 수 있습니다.
5. 오른쪽 아래 **내보내기**에서 **문제 PDF / 답지 PDF / 문제+답지 PDF** 중 하나를 누릅니다.
   - 1단/2단, 풀이 여백(없음·조금·많이·한 쪽에 한 문제), 문제+해설 배치(모두 모아서/번갈아), 쪽·번호 표시를 고를 수 있습니다.
   - 원본이 PDF면 글자가 선명한 벡터 그대로, 스캔본·사진이면 고해상도 이미지로 잘라 붙입니다.

### 인식이 틀렸을 때 – 페이지 검토·수정

**페이지 검토·수정** 탭에서 쪽마다 인식된 영역이 상자로 보입니다. 왼쪽 목록의 ⚠ 표시는 번호가 건너뛰는 등
확인이 필요한 쪽입니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 번호 고치기 | 상자 클릭 → 위쪽 `번호` 칸에 입력 |
| 영역 옮기기/크기 조절 | 상자를 끌기 / 빨간 모서리 끌기 |
| 빠진 문항 추가 | `문항 추가` → 빈 곳을 드래그 → 번호 입력 |
| 다음 단·쪽으로 이어지는 부분 추가 | 문항 선택 → `영역 추가` → 이어지는 부분 드래그 (다른 쪽으로 넘어가도 됨) |
| 삭제 | 상자 선택 → `삭제` 또는 Delete 키 |
| 이 쪽만 다시 인식 | `다시 인식` (로컬) 또는 `Gemini 인식` |
| 쪽 넘기기 | ← → 키 |

### Gemini 보조 인식 (선택)

1. [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료 API 키를 만듭니다.
2. 오답노트 **설정**에 키를 붙여 넣습니다. 모델은 기본값 `gemini-flash-latest` 를 쓰면 되고, `모델 목록`으로 다른 모델을 고를 수 있습니다.
3. 분석 패널의 **Gemini 보조**를 `애매한 쪽만`(권장) 또는 `모든 쪽`으로 바꾸고 분석합니다.
   검토 화면의 `Gemini 인식` 버튼으로 한 쪽씩 인식할 수도 있습니다.

- 무료 등급에는 분당/하루 요청 한도가 있어서, 설정의 `분당 요청 수`(기본 8)에 맞춰 천천히 보냅니다. 한도를 넘으면 로컬 인식 결과를 그대로 씁니다.
- 무료 등급에서는 보낸 페이지 이미지가 Google의 서비스 개선에 쓰일 수 있습니다. 민감한 자료라면 쓰지 마세요.

## 데이터 위치

오답노트마다 올린 파일 사본과 분석 결과가 `%APPDATA%\OhdapNote\data\projects\` 에 저장됩니다.
(설정 → 데이터 폴더 열기) 프로그램을 지워도 이 폴더는 남습니다.

## 새 버전 배포 (관리자용)

자동 업데이트는 이 저장소의 **GitHub Releases** 를 봅니다.

1. `package.json` 의 `version` 을 올립니다. (예: `0.1.0` → `0.1.1`)
2. 커밋 후 같은 버전의 태그를 푸시합니다.
   ```bash
   git tag v0.1.1
   ```
   ```bash
   git push origin v0.1.1
   ```
3. GitHub Actions 의 **Release (Windows)** 가 설치 파일(`OhdapNote-Setup-0.1.1.exe`)과 `latest.yml` 을 만들어 Release 로 올립니다.
4. 이미 설치된 프로그램들은 다음 실행 때 새 버전을 받아 설치합니다.

> 태그와 `package.json` 버전이 다르면 빌드가 멈춥니다. 저장소가 공개(public)여야 설치된 프로그램이 업데이트를 받을 수 있습니다.

`CI` 워크플로는 푸시할 때마다 테스트를 돌리고, 시험용 설치 파일을 Actions 의 Artifacts(`OhdapNote-Setup`)로 올립니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
```
```bash
npm start
```

| 명령 | 내용 |
| --- | --- |
| `npm start` | 개발 모드로 실행 (자동 업데이트는 꺼짐) |
| `npm test` | 단위 테스트 (번호 인식·매칭·빠른 선택 등) |
| `npm run test:fixtures` | 테스트용 가짜 문제집/답지/스캔본/사진 생성 (Playwright Chromium, Python Pillow·numpy, poppler 필요) |
| `npm run test:detect` | 생성한 문서로 인식 정확도 확인 (브라우저에서 실제 엔진 실행) |
| `npm run test:e2e` | Electron 앱을 띄워 올리기→분석→선택→내보내기→편집 전체 흐름 확인 (리눅스는 `xvfb-run -a npm run test:e2e`) |
| `npm run dist` | 윈도우 설치 파일 빌드 (`dist/`) – 윈도우에서 실행하거나 CI 사용 |

### 구조

```

src/main/preload.js       화면에 노출하는 API (window.ohdap)
src/renderer/js/
  app.js                  화면(홈·문항 선택·미리보기·내보내기·설정)
  editor.js               페이지 검토·수정 편집기
  docsource.js            PDF(pdf.js)·이미지를 쪽 단위로 렌더링, 텍스트 위치 추출
  layout.js               잉크 분석: 단 구분, 머리말/꼬리말, 여백 잘라내기
  detect.js               번호 후보 추출, 대표 스타일 학습 + 연속 번호 사슬(DP) 선택, 문항 영역 계산
  analyze.js              분석 파이프라인(텍스트 → OCR → 빠진 번호 재탐색 → Gemini)
  ocr.js                  Tesseract.js (한국어+영어, 오프라인)
  gemini.js               Gemini 보조 인식
  match.js                문제 ↔ 해설 짝 맞추기 (최장 공통 부분수열)
  exporter.js             pdf-lib 로 PDF 만들기
scripts/copy-vendor.mjs   pdf.js·Tesseract·pdf-lib 파일을 src/renderer/vendor 로 복사 (npm install 때 자동)
test/                     단위·인식·E2E 테스트
```

## 알아둘 점

- 문제집·답지 PDF는 개인 학습용으로만 사용하세요.
- 스캔본은 OCR 때문에 쪽당 2~3초 정도 걸립니다. 진행 중에 취소할 수 있습니다.
- 책마다 편집 모양이 달라 자동 인식이 완벽하지 않을 수 있습니다. ⚠ 표시된 쪽은 검토 화면에서 확인해 주세요.
