# 오답노트 (OhdapNote)

문제집과 답지(PDF 또는 사진)를 **책장에 한 번 등록**해 두면, 학생마다 **틀린 번호만 골라 시험지처럼 깔끔한 PDF**로
묶어 주는 윈도우용 수학 오답노트 프로그램입니다.

- **책장과 학생 오답노트가 따로**: 책(문제집+답지)은 한 번만 올려 분석하고, 오답노트를 만들 때 책장에서 골라 씁니다. 한 오답노트에 여러 권도 됩니다.
- 문제 번호를 자동으로 찾아 **쪽 번호와 함께** 표로 보여 줍니다(단원마다 1번부터 다시 시작하는 책도 OK).
- 4자리 연번(0001…), 예제·유제와 Level 01… 처럼 **번호 체계가 둘 이상 섞인 책**, `[0100~0102] 다음 글을 읽고…` 처럼
  **공통 지문이 따로 있는 문제**(지문을 문제와 함께 내보냄)도 인식합니다.
- **번호가 이어지지 않으면 의심**해서 알려 줍니다: 빠진 번호는 표에 `?` 로, 확인할 쪽은 따로 모아 보여 주고,
  사용자가 직접 보고 **문제없음 / 직접 고치기 / 꼼꼼히 다시 찾기 / AI에게 맡기기** 중에서 고릅니다.
- 답지 앞쪽의 **빠른 정답표는 자동으로 건너뛰고**, 단·쪽을 넘어가는 긴 해설도 이어 붙입니다. 문제집 뒤에 붙은 정답과 풀이도 자동으로 뺍니다.
- 디지털 PDF는 글자 위치로, 스캔본·사진은 OCR(문자 인식)로 번호를 찾습니다. 인터넷 없이 동작합니다.
  - 휴대폰 스캔 앱·스캐너가 쪽 위에 몰래 깔아 둔 OCR 글자(한글이 엉터리인 경우가 많음)는 믿지 않고 직접 다시 읽습니다.
  - 한 줄에 문항이 둘 이상 나란히 있는 편집(`0001 …   0002 …`), 색 상자 속 흰 번호(`0053 | 대표 문제`)도 찾습니다.
  - 스캔본도 "유형 15", "02-2 로그의 성질" 같은 제목 줄(색칠된 이름표)에서 문항 영역을 끊어, 제목 상자가 문항에 딸려 오지 않습니다.
  - 번호가 건너뛴 곳은 해상도를 바꿔 한 번 더 읽고, 그래도 없으면 번호 자리를 하나씩 잘라 숫자만 다시 읽습니다.
- 선택 기능: **AI 보조 인식** — 기본은 무료 **Gemini API**(Google AI Studio). 설정 → 세부 설정에서 **OpenAI 호환**(OpenAI · OpenRouter ·
  게이트웨이 · 내 컴퓨터의 Ollama/LM Studio — 인터넷 없이), **Claude**, **ChatGPT Plus/Pro 구독(Codex CLI)** 으로 바꿀 수 있습니다.
  **1순위·2순위 모델**을 정해 두면 한도가 찼을 때 자동으로 넘어갑니다.
- PDF는 **실제 시험지 양식**(제목, 학원·선생님·학생·점수 칸, 쪽 번호)으로 만들어집니다.
- **마고에듀 통합 클라우드**에서 설치·실행합니다. 같은 아이디의 컴퓨터끼리 실시간으로 맞춰지고,
  **같은 학원 선생님끼리 책장(교재)과 학생 오답노트를 함께 씁니다.** 교재에는 "생성자: 이름"이 붙고, 만든 사람과 원장만 고칠 수 있습니다.
  학생 명단과 학원 AI 는 통합 클라우드에 있습니다 (통합 클라우드 1.2.0 이상).

개발: **구현민**

## 설치

**마고에듀 통합 클라우드**에 로그인한 뒤 프로그램 목록에서 **오답노트 → 설치·열기**를 누릅니다.
(오답노트만 따로 깔거나 exe 를 직접 켜면 "통합 클라우드에서 켜 주세요" 안내가 뜹니다.)

- 업데이트는 통합 클라우드가 맡습니다. 새 버전을 받아 두면 오답노트를 다음에 켤 때 새 버전으로 켜집니다. (오답노트 안에는 업데이트 확인이 없습니다.)
- 예전에 따로 설치해서 쓰던 오답노트가 있으면 처음 켤 때 통합 클라우드가 **예전 데이터를 가져올지** 물어봅니다.
  가져오면 책은 학원 책장으로(생성자 = 나), 오답노트는 내 오답노트로, AI 키 같은 설정은 내 설정으로 옮겨집니다. 원래 폴더는 지우지 않습니다.

### 학원에서 함께 쓰기

- **책장**: 같은 학원 선생님이 등록한 책이 모두 보이고 바로 오답노트에 쓸 수 있습니다. 책에는 **생성자: 이름**이 붙고,
  고치거나 지우는 것은 만든 사람과 원장만 할 수 있습니다. 남의 책을 고쳐 쓰고 싶으면 **내 책으로 복사**를 누릅니다.
- **교재 파일(PDF·사진)은 열 때만 받습니다.** 목록과 분석 결과는 바로 보이고, 책을 열거나 내보낼 때 원본을 받아 옵니다.
- **과목**: 학원이 마고에듀와 계약한 과목(수학·영어·국어)의 교재만 등록할 수 있습니다. 계약에서 빠진 과목의 교재는 책장에 그대로 있지만
  **보기만** 됩니다 (고치기·분석·오답노트에서 고르기·내보내기·문제은행 막음). 과목이 없던 예전 교재는 수학으로 봅니다.
  운영자가 계약을 바꾸면 켜 둔 오답노트에도 바로 반영됩니다.
- **학생 명단**은 통합 클라우드에 있고 학원 사람 누구나 추가·고치기·지우기를 할 수 있습니다 (담당 선생님도 정함).
  지운 학생은 30일 안에 누구나 되살릴 수 있고, 그 뒤에는 그 학생의 오답노트와 함께 완전히 지워집니다.
- **학생 오답노트**는 학생마다 모여 있고 **학원 사람 누구나 이어서 고칠 수 있습니다.** 담당 선생님이 바뀌어도 그대로 이어 갑니다.
  두 사람이 같은 노트를 동시에 고치면 저장할 때 합쳐집니다 (고른 문항은 둘 다 남고, 둘이 같은 칸을 고쳤으면 나중에 저장한 쪽).
  지운 학생의 오답노트는 보기와 내보내기만 됩니다. 다른 선생님의 나만 보기 교재를 쓰는 노트에서는 그 책이 '볼 수 없는 교재'로 보입니다.
- 학생을 정하지 않은 오답노트는 각 선생님 것입니다. 원장은 볼 수 있지만, 보기와 내보내기만 됩니다.
- **학원 AI**: 원장이 통합 클라우드의 '학원 AI' 에서 정하면 학원 사람 모두가 같이 씁니다.
  키는 통합 클라우드 서버에만 있고 선생님 컴퓨터로 오지 않습니다. 오답노트가 서버에 AI 요청을 보내면 서버가 키를 붙여 대신 보냅니다
  (학원 AI 주소가 학원 안 주소면 각 컴퓨터에서 그 주소로 바로 부릅니다).
  각자 **설정 → AI 보조 인식** 에서 '학원 AI 쓰기' 와 '내 키 쓰기' 중에 고릅니다.

## 사용법

### 1. 책장에 책 등록 (한 번만)

1. 첫 화면 **책장** 탭 → **새 책 등록** → 이름 입력 (예: `쎈 수학Ⅰ`) → **과목** 고르기 (학원이 계약한 과목만 보여요. 책 화면 위쪽에서 바꿀 수도 있어요)
2. **문제집**과 **답지** 칸에 파일을 끌어다 놓거나 클릭해서 고릅니다.
   - PDF 1개, 또는 사진(JPG·PNG) 여러 장(파일 이름 순서대로 쪽이 됩니다). PDF 여러 개는 이름 순서대로 이어 붙입니다.
3. 칸마다 따로 있는 **[문제집 분석]**, **[답지 분석]** 버튼을 누릅니다. (분석 중에는 **멈추기**로 바로 멈출 수 있어요. **백그라운드에서 계속**을 누르거나 다른 화면으로 가도 분석은 뒤에서 계속돼요)
   - **쪽 범위**: 예) `5-180`, `3-10, 15`. 답지는 앞쪽 *빠른 정답* 표를 빼 주면 짝 맞추기가 더 정확합니다.
     문제집 PDF 뒤에 *정답과 풀이*가 함께 붙어 있으면 그 앞의 빠른 정답표 쪽부터 자동으로 빼고 그 쪽에 알려 줍니다. 문제 쪽까지만 지정하면(예: 수능특강 `1-101`) 더 빠릅니다.
   - **번호 모양**: 보통 `자동`. 잘 안 잡히면 `1. 2. 3.` / `0001` 등으로 직접 지정하세요.
   - **다음 단·쪽으로 이어짐**: 해설이 다음 단·다음 쪽으로 넘어가는 경우(답지는 기본으로 켜짐).
   - **PDF 1쪽 = 책 ○쪽**: 표에 책에 인쇄된 쪽 번호로 보이게 맞춥니다(쪽번호가 글자로 있으면 자동).
4. **인식 결과** 탭에서 쪽마다 찾은 번호를 확인합니다.
   - **확인이 필요한 쪽**이 위에 모여 나옵니다(번호가 건너뛰었거나 인식이 애매한 쪽). 쪽마다
     - **검토**: 페이지를 보며 직접 고치기
     - **꼼꼼히 다시 찾기**: 그 쪽만 고해상도 OCR + 앞뒤 쪽 번호에 맞춰 더 꼼꼼히 다시 찾기
     - **AI**: 그 쪽을 AI에게 맡기기 (여러 쪽을 체크해서 한 번에 보낼 수도 있음)
     - **문제없음**: 이대로 괜찮으면 표시 지우기
   - 표에서 `116 ?` 처럼 점선으로 보이는 칩은 **번호 순서상 있어야 하는데 못 찾은 번호**입니다. 누르면 그 쪽이 열립니다.

### 2. 학생 오답노트 만들기

1. 첫 화면 **학생 오답노트** 탭 → **새 오답노트** → 학생 이름·제목을 쓰고 **책장에서 책을 고릅니다**(여러 권 가능).
2. 쪽마다 번호 버튼이 나옵니다. 틀린 번호를 누르세요.
   - 번호에 마우스를 올리면 오른쪽에 문제와 해설이 미리 보입니다.
   - 쪽 번호 버튼을 누르면 그 쪽 문항을 한꺼번에 선택/해제합니다.
   - **빠른 선택** 칸: `12쪽: 3, 5, 7-9` 처럼 쪽과 번호로, 또는 `15, 22` 처럼 번호만 입력.
   - 점선 번호는 답지에서 짝을 못 찾은 것입니다. 미리보기에서 짝을 직접 고를 수 있습니다.
   - 책이 여러 권이면 위쪽 책 탭으로 바꿔 가며 고릅니다.
3. 오른쪽 **시험지로 내보내기**
   - **시험지 머리**: 제목, 학생, 학원, 선생님, 날짜 (학원·선생님 기본값은 **설정**에서 저장)
   - **문제지** / **해설지** / **문제 + 해설(문제마다 바로 뒤에)** / **문제 + 해설(해설은 맨 뒤에)**
   - 1단/2단, 풀이 여백(없음·3cm·8cm·한 쪽에 한 문제), 출처(책·쪽·번호)·새 번호 표시를 고를 수 있습니다.
   - 공통 지문이 있는 문제는 지문을 함께 싣습니다(같은 지문의 문제가 이어지면 한 번만).
   - 원본이 PDF면 글자가 선명한 벡터 그대로, 스캔본·사진이면 고해상도 이미지로 잘라 붙입니다.
   - **파일: 한글(HWPX)** 을 고르면 한글(2014 이상)에서 고칠 수 있는 `.hwpx` 로 저장합니다. AI 를 설정해 두면 문제·해설을
     글자와 **한글 수식**(수식 편집기로 고칠 수 있음)으로 옮기고, 그래프·도형은 잘라서 그림으로 넣습니다.
     AI 설정이 없거나 옮기지 못한 문항은 그림으로 들어갑니다. 옮긴 결과는 책 폴더에 저장해 두어 다시 내보낼 때는 묻지 않습니다.

### 3. 문제은행

1. 첫 화면 **문제은행** 탭 → 교재의 **문제은행에 넣기**. 책장에서 분석한 문항을 글자·수식으로 옮깁니다.
   디지털 PDF는 PDF 글자로, 스캔본은 이 컴퓨터의 OCR로 옮깁니다. **AI는 기본으로 쓰지 않으며**, 직접 체크했을 때만 미덥지 않은 OCR 결과를 보완합니다.
   스캔본은 설정에서 수식 인식 모델을 먼저 받아 주세요. 다른 일을 하며 기다릴 수 있고, 멈춘 뒤에는 **이어서 넣기**로 계속합니다.
2. 과목·책·쪽·번호·글자로 찾고 체크칸을 눌러 **시험지 바구니**에 담습니다. 지문의 글로도 찾을 수 있고 **세트 모두 담기**도 됩니다.
   문항을 누르면 문제·해설 그림과 옮긴 글이 보입니다. **글 고치기**에서 문항·지문을 따로 고칠 수 있습니다.
3. 오른쪽에서 시험지 머리·배치·풀이 여백을 정하고 문제지·해설지를 **PDF / 한글(HWPX)**로 저장합니다.
   이어지는 같은 지문은 한 번만 싣고, 새 번호는 문제에만 붙입니다. 고친 문제 글은 한글 내보내기에 먼저 쓰며 문제 PDF는 원본 그대로입니다.

담은 문항·설정은 이 컴퓨터에 남습니다. 옮긴 글은 학원 안에서만 함께 쓰며, 남의 책에서 내가 옮기거나 고친 글은 내 폴더에만 저장됩니다.
학원 계약에 없는 과목의 교재는 흐리게 표시되고 **보기만** 됩니다. 문항 넣기·담기·고치기·내보내기에서는 제외됩니다.

### 4. 정답·해설 직접 쓰기

1. 문제은행·책·오답노트의 문항 미리보기에서 **정답·해설 쓰기**를 누릅니다. 답지 파일이 없어도 됩니다.
2. 위에는 정답을, 아래에는 풀이를 씁니다. **수식** 단추(또는 `Ctrl+N` 다음 `M`)로 수식을 넣고, 그림은 복사해서 붙여 넣거나 끌어다 놓으세요.
   수식 창은 **위 미리보기 → 틀·기호 도구 → 아래 한글 스크립트** 순서입니다. 위 수식을 누르면 해당 글을 고칠 수 있고, 넣기 전 취소하면 본문은 그대로입니다.
   **Tab / Shift+Tab**으로 칸 이동, **Shift+Esc**로 넣기. **단축키 / F1**에서 공식 키 22개와 문법을 확인하세요. 선택한 수식에서 **P**를 눌러 다시 고칠 수 있습니다.
3. **저장은 저절로 됩니다.** 위의 ‘저장됨’을 확인하세요. 잘못 고쳤으면 **되돌리기**(`Ctrl+Z`), 다시 하려면 `Ctrl+Y`를 누릅니다.
4. 짝 답지가 있으면 **답지 인식 결과 불러오기**로 읽어 둔 글을 가져옵니다. 디지털 PDF는 바로 읽으며, 이미 쓴 내용은 바꾸기 전에 확인합니다.
5. 직접 쓴 해설은 답지보다 먼저 내보냅니다. 풀이 없이 정답만 쓰면 ‘정답 ③’처럼 나갑니다. **PDF는 글자 검색·선택이 되고, 한글(HWPX)은 글·수식·그림을 다시 고칠 수 있습니다.**

만든 사람과 원장만 고칠 수 있고, 다른 선생님은 **정답·해설 보기**로 읽습니다. 학원 공유 교재의 해설은 다른 컴퓨터에도 함께 보입니다.

### AI 보조 인식 (선택)

자동 분석은 AI 를 쓰지 않습니다. AI 는 두 군데서만 씁니다.

- 인식 결과의 **확인할 쪽**에서 사용자가 고른 쪽만 AI 로 보내 문항 위치를 다시 찾습니다.
  진행 창에서 쪽마다 결과가 보이고, **취소**를 누르면 보내던 요청까지 바로 끊습니다.
- **한글(HWPX)로 내보낼 때** 내보내는 문항(고른 문제·해설)의 그림을 AI 로 보내 글자·수식으로 옮깁니다.
  처음 옮기는 문항만 보내고(진행 창·취소 같음), 한 번 옮긴 문항은 다시 보내지 않습니다. PDF로 내보낼 때는 쓰지 않습니다.

기본은 **Google Gemini** 입니다.

1. [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료 API 키를 만듭니다.
2. **설정**에 키를 붙여 넣고 **1순위 모델**(기본 `gemini-flash-latest`)과 **2순위 모델**을 정합니다.
   `모델 목록`을 누르면 쓸 수 있는 모델이 나오고, 칩을 누르면 1순위, Shift+누르면 2순위로 들어갑니다.

- 1순위 모델의 한도가 다 차거나(429) 쓸 수 없으면 자동으로 2순위 모델로 넘어갑니다.
- 무료 등급에는 분당/하루 요청 한도가 있어서, 설정의 `분당 요청 수`(기본 8)에 맞춰 요청을 시작하는 간격을 둡니다.
- 무료 등급에서는 보낸 페이지·문항 이미지가 Google의 서비스 개선에 쓰일 수 있습니다. 민감한 자료라면 쓰지 마세요.

#### 다른 AI 쓰기 (설정 → 세부 설정 → AI 종류)

| AI 종류 | 넣을 것 | 비고 |
| --- | --- | --- |
| Google Gemini (기본) | API 키, 모델 | 세부 설정에서 **게이트웨이 주소**(예: Cloudflare AI Gateway, `/v1beta` 앞까지)를 넣을 수 있음 |
| OpenAI 호환 | 주소, API 키(로컬이면 비움), 모델 | OpenAI(`https://api.openai.com/v1`), OpenRouter(`https://openrouter.ai/api/v1`), LiteLLM·Cloudflare AI Gateway 같은 게이트웨이, 로컬 서버. 그림을 읽는 모델이어야 함 |
| Anthropic Claude | API 키, 모델(기본 `claude-opus-5-5`, 바꿀 수 있음) | 공식 SDK 로 Messages API 호출. 세부 설정에서 게이트웨이 주소 |
| ChatGPT Plus/Pro 구독 | (없음) | 아래 Codex CLI 참고 |

**로컬로(인터넷 없이)**: 내 컴퓨터에서 [Ollama](https://ollama.com)(`http://localhost:11434/v1`), LM Studio(`http://localhost:1234/v1`),
llama.cpp 서버(`http://localhost:8080/v1`)에 그림을 읽을 수 있는 모델(예: `qwen2.5vl:7b`)을 띄우고, AI 종류를 **OpenAI 호환**으로 바꿔
주소와 모델 이름만 적으면 됩니다(API 키는 비움). 문항 그림이 컴퓨터 밖으로 나가지 않고, 사용 한도도 요금도 없습니다.
작은 모델이 그림 여러 장을 한 번에 잘 못 읽으면 세부 설정의 `묶음 크기`를 1로 두세요.

**ChatGPT Plus/Pro 구독으로(Codex CLI)**: API 요금 없이 구독 사용량으로 처리합니다.

1. 공식 [Codex CLI](https://github.com/openai/codex) 를 설치하고, 명령 프롬프트에서 `codex login` 으로 ChatGPT 계정에 로그인합니다.
2. 설정 → 세부 설정 → AI 종류에서 **ChatGPT Plus/Pro 구독 (Codex CLI)** 을 고르면 CLI 를 찾았는지, ChatGPT 계정으로 로그인했는지 보여 줍니다.
   (못 찾으면 세부 설정에 `codex` 경로를 적어 주세요.)

- 오답노트는 로그인 정보(`~/.codex`)를 읽지 않고 API 키도 넘기지 않습니다. 요청마다 임시 폴더에서
  `codex exec` 를 **읽기 전용 샌드박스**로 실행해 그림을 붙여 보내고 JSON 답만 받습니다. 취소하거나 시간이 넘으면 codex 를 끕니다.
- 한 요청에 수십 초 걸릴 수 있고, 구독의 사용 한도가 차면 남은 문항은 그림으로 들어갑니다.

#### 더 빠르게 (한글 내보내기)

- 문항 여러 개를 **한 요청에 묶어**(세부 설정 `묶음 크기`, 기본 4) 보내고, 요청 여러 개를 **동시에**(`동시 요청 수`, 기본 3) 보냅니다.
  분당 요청 수는 요청을 시작하는 간격으로만 지킵니다. 묶음 답을 읽지 못하면 그 문항들만 하나씩 다시 보냅니다.

## 자동 빌드·배포 (관리자용)

통합 클라우드는 이 저장소의 **GitHub Releases** 에서 `OhdapNote-x.y.z-win-x64.zip`(안에 `magoedu-app.json`)을 받아 설치·업데이트합니다.
`magoedu-app.json` 은 저장소 맨 위의 것을 빌드할 때 지금 버전으로 넣습니다 (`scripts/write-manifest.mjs`).

### 자동 (기본)

**main 에 앱 코드가 바뀌어 올라오면(푸시 또는 PR 병합) 알아서 배포됩니다.**
`Release (Windows)` 워크플로가

1. 버전을 정하고 — 지금 버전이 이미 배포됐으면 patch 를 1 올려 커밋 (`0.1.0` → `0.1.1`)
2. 태그(`v0.1.1`)를 만들고
3. 빌드한 폴더에 `magoedu-app.json` 을 넣어 `OhdapNote-0.1.1-win-x64.zip`(+ `.sha256`)으로 묶어 Release 로 올립니다.
4. 업데이트 내용은 지난 버전 이후의 커밋 제목으로 자동 작성됩니다.

README·테스트만 바뀐 푸시는 배포하지 않습니다. 첫 배포(v0.1.0)의 업데이트 내용은 `RELEASE_NOTES.md` 를 씁니다.

### 직접 정하고 싶을 때

- **큰 버전 올리기**: GitHub → **Actions** → **Release (Windows)** → **Run workflow** → `minor`(0.1.x → 0.2.0) / `major`(→ 1.0.0) 선택, 업데이트 내용 입력
- **명령으로**: `npm run release:minor` (버전 올려 커밋·태그 푸시 → 같은 워크플로가 배포, 태그 메시지가 업데이트 내용)

> 워크플로가 main 에 버전 커밋과 태그를 올리므로, main 에 "PR 필수" 같은 브랜치 보호를 걸면 자동 버전 올리기가 막힙니다.

> 저장소가 비공개라면 마고에듀 서버의 `GITHUB_TOKEN` 에 읽기 토큰을 넣어야 통합 클라우드가 받을 수 있습니다.

`CI` 워크플로는 푸시·PR 마다 테스트를 돌리고, main 이 아닌 브랜치는 시험용 묶음을 Actions 의 Artifacts(`OhdapNote-zip`)로 올립니다.

## 알아둘 점

- 문제집·답지 PDF는 개인 학습용으로만 사용하세요.
- 스캔본은 OCR 때문에 시간이 걸립니다. 코어 16개 노트북에서 문제집은 쪽당 2초쯤, 글이 빽빽한 답지는 쪽당 3~4초쯤이고, 코어가 적으면 더 걸립니다. 진행 중에 취소할 수 있습니다.
- 오래 걸리는 작업(분석, AI 인식, 한글 문서로 옮기기)은 **백그라운드에서 계속**을 눌러 두고 다른 책이나 오답노트를 봐도 됩니다. 위쪽 막대에 진행 상황이 보이고, 누르면 진행 창(또는 그 책)이 다시 열려요. 끝나면 알림이 뜨고 결과는 그 책에 저장돼요(한글 문서는 알림의 **저장하기**로 저장). 작업이 남아 있을 때 프로그램을 끄면 한 번 더 물어봐요.
- 책마다 편집 모양이 달라 자동 인식이 완벽하지 않을 수 있습니다. **확인이 필요한 쪽**은 꼭 한 번 봐 주세요.
