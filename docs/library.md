# 마고 공용 책장

런처가 `MAGOEDU_LIBRARY_DIR`로 알려 주는 받기 전용 폴더를 읽어요.
`books/<책 id>/` 안에 `book.json`, `transcripts.json`, `answers.json`이 있어요.
문제·해설 PDF는 미리보기·내보내기·복사 때만 런처에 요청해요.
앱은 공용 폴더를 고치지 않아요. 고치려면 문항 미리보기에서 **내 책으로 복사**하세요.

문제은행에서는 계약 과목의 공용 책만 보여요. 책장에는 개별 카드가 없어요.
시험 종류 또는 연도를 고르면 해당 시험의 문항·정답·옮긴 글을 읽어요.
월·학년·과목으로 더 좁힐 수 있어요. 수능은 11월로 찾아요.
책 목록 요약은 파일 수정 시각·크기로, 읽은 문항은 `updatedAt`으로 캐시해요.
