# 모의고사 파일 가져오기: 논리 API

화면·다운로드·ZIP 일괄 처리는 포함하지 않는다. 호출자가 로컬 파일을 읽고 PDF.js 문서를 `fontExtraProperties: true`로 연다. 정답표는 `getTextContent().items`를 내용 순서로 넘긴다. 쪽별 결과를 과목/선택 키로 병합할 때 충돌을 확인해야 한다.

| 함수 | 입력 → 출력 |
|---|---|
| `identifyExam` (mockexam.js) | `{filename, path, text}` → 시험 종류·시행연도·학년도·월·학년·과목·파일 역할·선택·홀짝·듣기 범위·확신도·이유 |
| `groupExamFiles` | 파일 배열(`metadata` 선택) → 동일 시험/과목/선택/홀짝별 그룹. 미확인 파일은 자동 병합하지 않음 |
| `normalizeHancomText` (hancom.js) | 글자, 선택 글꼴명 → 확인한 PUA 문자 치환. 모르는 코드는 보존 |
| `readPageLayer` (pdfmath.js) | PDF.js 쪽, 라이브러리 → 글자·선·도형 좌표 |
| `transcribeParts` | `{layer,rect,place}[]` → 기존 블록. 한컴 math는 `eq`, 문단은 기존 `$…$` 표기와 `low` |
| `importAnswerBlocks` (answer-model.js) | 블록 → 한글 수식 `eq` 런. `review:true`로 확인 표시 전달 |
| `parseAnswerKey` (mockexam-answers.js) | 문자열 또는 PDF.js items, 선택 기본 과목/선택 → `{answers, warnings}` |
| `answerKeyToAnswers` | 파싱 결과, `과목\|선택`, 번호→문항 ID → `{version:1,items:{id:{answer,blocks:[]}}}` |

## 확인 규칙과 제한

- PUA 대응 175개는 설치 글꼴 cmap·코드별 렌더 대조. `scripts/inspect-hancom.py`는 글꼴을 읽기만 하며 코드·이름을 출력한다. `--build`는 검토한 대응과 두 글꼴의 cmap을 확인한 뒤 `hancom-map.js`를 재생성한다. 조사용 fontTools는 프로젝트 의존성에 추가하지 않는다. 저장소에 원본 글꼴·윤곽·시험 내용 없음.
- 한컴도 EH와 같은 분수선·첨자·극한 등 위치 복원 경로를 사용한다. 미해독 루트/시그마/행렬/연립 조각 등은 추측하지 않고 원본 영역 그림+`low`로 돌려준다. 현재 한컴 전사 결과는 모두 확인 대상이다. EH 반환 형식은 변경하지 않는다.
- 일반 문자열 정규화에서 글꼴명을 생략하면 한컴 대응으로 간주한다. 다른 글꼴 PUA일 수 있으면 실제 글꼴명을 전달한다. 미확인 PUA는 삭제하지 않는다.
- 공통 답은 `korean`, `math`, 선택 답은 `korean|화법과작문`, `math|미적분`처럼 분리한다. 변환 시 선택 답과 공통 답을 합칠 수 있다. 배점 없는 자료는 `points:null`.
- 정답 파서는 내용 순서의 번호/정답 쌍 또는 번호/정답/배점 열을 지원한다. 좌표만으로 다단 표를 재배열하거나 이미지 정답표를 읽지는 않는다. 정답 충돌·미확인 코드는 `warnings`로 반드시 확인한다.
- 합권·불명 과목은 자동 세트 결합하지 않는다. 일반 숫자만 있는 훼손 표는 복구 보장하지 않는다. 호출자는 예상 문항 수·번호 누락도 확인해야 한다.
- 듣기 범위는 확인된 2003~2027학년도 수능/모평 체제에만 제시한다. 학평이나 체제 미확인 시험은 `null`.
- 해설 문항 분할·화면·일괄 처리는 다음 단계. 문제지 실물 표본 필요.

`node scripts/check-mockexam.mjs <로컬 정답표.pdf>`로 쪽 1의 과목별 개수·PUA 코드·블록 통계만 점검할 수 있다. 파일 내용이나 글꼴을 저장하지 않는다.

## 2024학년도 실물 구조 측정 (2026-11-09)

원본은 저장소 밖에서 읽기만 했다. 아래에는 내용·그림·답 대신 집계만 기록한다.
PDF.js CMap을 지정하고, 식별은 첫 쪽 글자와 파일명, 정답은 첫 쪽 items를 입력했다.

| 검사 | 수정 전 | 수정 후 |
|---|---|---|
| 식별: 종류·시행연도·학년도·월·학년·과목·역할·선택 | 14/21 | 21/21 |
| 국어 정답: 6월 / 9월 / 수능 | 37/56 · 34/56 · 35/56 | 모두 56/56 |
| 수학 정답: 6월 / 9월 / 수능 | 23/46 · 22/46 · 22/46 | 모두 46/46 |
| 영어 정답: 6월 / 9월 / 수능 | 1/45 · 1/45 · 45/45 | 모두 45/45 |
| 수학 잔여 PUA: 6월 / 9월 / 수능 | 184/1948 · 195/1890 · 528/4584 | 0/1948 · 0/1890 · 0/4584 |

정답표 9개 모두 경고 0. 국어 공통 34개/76점, 선택 각각 11개/24점;
수학 공통 22개/74점, 선택 각각 8개/26점; 영어 45개/100점.
공통+선택 조합별 100점 확인. 수능 정답표는 첫 쪽(홀수형)만의 결과이며 짝수형 병합 검증은 별도다.
이는 번호 범위·개수·배점 검증이며, 모든 정답을 사람이 원본과 대조했다는 뜻은 아니다.

### 수식 전사

각 수학 문제지 1~3쪽, 왼쪽 본문 영역 `(x=.04,y=.12,w=.44,h=.78)`을
실제 `readPageLayer` → `transcribeParts({explain:true})`로 실행했다.

| 표본 | 완전한 글자·수식 전사 영역 | low 영역 | low 없는 오전사 |
|---|---|---|---|
| 6월 3영역 | 0/3 | 3/3 | 0/3 |
| 9월 3영역 | 0/3 | 3/3 | 0/3 |
| 수능 3영역 | 0/3 | 3/3 | 0/3 |

9영역 모두 원본 그림+`low:math`로 보류. 완전 전사율 0%, low 100%,
무표시 오전사 0%. **수식 자체가 출력되지 않아 개별 수식 정확도는 산출할 수 없다.**
PUA 잔여 0을 수식 복원 성공으로 해석하면 안 된다. 큰 분수선·루트·벡터 화살표·조각 괄호의
배치 복원과 수식별 원본 대조가 다음 단계다. 부분 그림에도 low를 유지하도록 보강했다.

### 문항 나누기: 기존 analyzeDocument, 외부 인식 호출 없음

전체 쪽, `role:problem`, `flow:column`, 과목별 설정으로 실행했다.
수능 문제지는 홀·짝 합본. 국어는 한 형 기준 45개가 아니라 **공통34+선택11×2=56개**다.

| 회차 | 과목 | 쪽 | 문항 결과/기대 | 지문 붙은 문항 / 지문 묶음 |
|---|---|---:|---:|---:|
| 6월 | 국어 | 20 | 49/56 | 45 / 11 |
| 6월 | 수학 | 20 | 46/46 | 0 / 0 |
| 6월 | 영어 | 8 | 45/45 | 20 / 7 |
| 9월 | 국어 | 20 | 54/56 | 51 / 13 |
| 9월 | 수학 | 20 | 46/46 | 0 / 0 |
| 9월 | 영어 | 8 | 45/45 | 15 / 6 |
| 수능 | 국어 | 40 | 110/112 | 104 / 27 |
| 수능 | 수학 | 40 | 92/92 | 0 / 0 |
| 수능 | 영어 | 16 | 90/90 | 30 / 12 |

- 수학: 공통1~22, 선택23~30 세 번 모두 보존. 6·9월 각각 9~12/13~16/17~20쪽에 선택 8개씩. 수능은 같은 구조 두 세트. 선택 전환의 번호 되돌림 경고는 남아 있다.
- 국어: 1~12쪽 공통, 13~16쪽 화작, 17~20쪽 언매. 9월 언매 37·39번 누락. 수능은 같은 구조 두 세트에서 합계 2개 누락. 6월에는 언매 구간 누락과 20쪽 본문 1~4 혼입이 관찰됐다. 첫 실행에서는 60개도 관찰되어 재현 안정성 검증이 필요하다.
- 지문(약속 5): `stem`, `stemLabel`, `stemId` 연결은 작동하지만 묶음 개수만으로 정답 판정 불가. 6월 영어의 25~34, 두 회차 영어의 31~34는 실제 공통 지문이 아닌 안내 범위가 지문으로 승격된 사례다. 16~17 듣기 묶음·41~42·43~45와 분리해야 한다.
- 작게 고치기 어려운 범위: 시험 전용 구간 경계, 홀짝 구간, 공통/선택별 기대 번호 사슬, 본문 목록 제외, 안내 문구와 진짜 지문 제목 구별. 기존 범용 문제집 검출에 전역 규칙을 더하지 않았다.
- 다음 구조 제안: 기존 문항 `id`, `num`, `rects`, `stem*` 유지. 선택 필터링용 `examSection:{subject,selection,form}`를 문항에 선택적으로 추가한다. 공통은 `selection:null`, 선택은 정답표와 같은 정규명. 페이지 제목으로 구간을 확정한 뒤 전파하고, ID는 번호만으로 다시 만들지 않는다. 같은 23번·35번, 홀짝·선택별 정답 결합을 `(form,subject,selection,num)`으로 한정한다. 미확정 구간은 자동 결합하지 않는다.
